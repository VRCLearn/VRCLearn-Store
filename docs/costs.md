# 费用与容量

## 计费边界

Workers Static Assets 的直接静态请求免费；API、详情 HTML、资产未命中后执行的 Worker 和其他动态处理按 Workers 计费。`run_worker_first` 只控制顺序，不是收费调用白名单。项目未启用 Workers Cache，不能把普通静态缓存与该产品混为一谈。[官方静态资源计费](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)

Workers Paid 基础费和包含额度按账户计算，同账户其他项目也会消耗额度；动态请求、CPU、D1、R2、KV、DO 和日志均须按实际使用核对。单独 Worker 不等于独立账单或独立基础订阅。[官方计费](https://developers.cloudflare.com/workers/platform/pricing/)

当前没有账户账单查询 Worker、预算状态分发、金额阈值告警或紧急停机机制，也不发送认证邮件。费用由所有者在 Cloudflare 核对；业务配额和 CPU 限制不能构成账单硬上限。每月 10–20 美元只是容量设计目标，不是实际费用承诺。

## 业务配额

- 公共动态读取按可信客户端 IP 限制 60 次/分钟、1,000 次/日，站点合计 45,000 次/日。DO 原子检查失败即拒绝，不能在配额服务异常时放行。
- 商品每次最多 10 张图片、每张 2 MiB，只接受实际有效的 JPEG、PNG、WebP，并校验尺寸；不接收视频或模型文件。
- 上传每账户 100 次/日、全站 1,000 次/日、全站 2 GiB/UTC 日历月写入字节预留。失败不自动退还，重放不重复写入。
- 提交审核每账户 20 次/日、全站 1,000 次/日；举报每账户 10 次/日。其他修改有按操作的分钟限制，数据库还有全站/店铺存储计数与限制。
- 密码认证保留原子账户/IP 配额与独立认证限流；主 Worker CPU 为 50 ms，辅助 Worker 500 ms。密码安全参数不为减少 CPU 而降低。

这些是业务操作额度，不代表 Cloudflare 实际请求、CPU 或美元费用额度。已被拒绝的动态调用本身仍可能计费，攻击流量和同账户其他项目也不受这些业务计数保证。

## 有界行为

前端不轮询、不无限滚动；搜索在提交后发起，取消过期请求，429 不自动重试。公开内容缓存最长 60 秒，缓存键包括地区、语言和规范化查询；私人响应禁止共享缓存。

后台清理每十五分钟执行固定批次，媒体、草稿及会话按索引扫描，不循环排空整库。业务 DO 账本最多 100,000 条，获准请求清理最多 32 条过期记录，Alarm 每批最多 1,000 条，避免无界写放大。

不逐次写入浏览/点击量，不做热门榜。日志只记录脱敏事件并配置采样；构建请求、锁等待和恢复流程同样有时限与次数上限。

## 容量验证

`npm run test:capacity` 在内存 SQLite 中按约 100 家商家、10,000 件商品验证索引、FTS 和分页行为。它不代表云端 D1 的延迟、真实缓存命中率、日活 1,000 的负载结果或实付费用；上线后须结合实际用量复核。

测试库、桶及 DO 从空状态开始，不复制旧账本或配额。正式公开前须与所有者确认内测数据、媒体及配额重置范围，并执行 [上线前检查](operations.md#正式公开上线前)。
