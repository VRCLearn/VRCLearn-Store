# 架构

## Workers 与静态界面

主 Worker 使用 Static Assets 分发 React、TypeScript 与 Material Web 界面。首页、搜索、收藏、账户、商家工作台、管理工作台及说明页生成真实静态 HTML；匹配的静态资源直接由资产服务响应。未使用全站服务端渲染或全站登录态检查，不轮询账户或搜索。

动态入口为 `/api/v1/*`、`/api/auth/*`、三语商品/店铺详情、`/sitemap.xml` 与 `/sitemaps/*`。路由清单由 `shared/routes.json` 统一提供，构建与运行时共用。详情 HTML 包含正文、分享元数据和结构化数据，API 与 HTML 共用业务服务层，不通过 HTTP 请求自己。

资产路由采用 `404-page`，不把 API、详情或缺失资源降级成 SPA HTML。`run_worker_first` 只确定执行顺序，不是函数调用白名单；缺失路径仍可能调用 Worker，应快速拒绝且不查询数据库。新 Workers Cache 未启用。

主 Worker CPU 限制 50 ms；内部辅助 Worker 500 ms，保留密码计算所需预算。认证通过本环境 Service Binding 调用，DO 承担原子业务配额；辅助 Worker 不配置公共域、默认域或预览 URL。Vite 在同一次构建中输出前端、主 Worker 和辅助 Worker。

## 数据、认证与地区

D1 保存基本账户、商家、修订、分区发布、审核、收藏、举报、媒体索引及审计记录。R2 私有桶保存待审图片，公开桶保存审核通过的地区副本；KV 保存目录缓存版本。每商品最多 10 张图，每张 2 MiB，校验实际类型与像素尺寸。

当前使用 Better Auth 邮箱密码认证。邮箱仅为登录标识，不证明所有权；仅有昵称，没有 username。注册后可登录，无邮箱验证、邮件找回密码、MFA 或认证发信。内部账户 ID 与权限独立于邮箱；管理员显式授予，不允许凭同名邮箱自动关联未来 Loginflare 身份。

地区取 Cloudflare 的可信 IP 国家：大陆为 CN，港澳台及其他已知地区为国际区，未知拒绝商品内容查询。API、HTML、收藏、媒体及 sitemap 都服务端过滤；缓存键包含地区、语言和规范化查询，私人响应不进入共享缓存。公开 HTML 最长缓存 60 秒，发布和下架更新目录版本，不触发全站构建。

Adult 商品不可提交 CN 审核；已有 CN 发布时，先下架 CN 后才能提交 Adult 修订。首次发布按区审核，已上架内容修订须通过全部当前上架区后统一替换；审核决定关联具体修订，使用 D1 原子批处理切换。

## 卡密与私密交付

商品使用外部兑换码购买链接，站内只负责核销与显示商家导入的独立文本或链接，不托管商品文件。卡密仅以商品范围内的 SHA-256 摘要保存，交付内容保存在 D1 私有库存表，不加入公开商品、SSR、收藏或推荐数据。库存接口只向商品所属商家提供计数。

导入是带容量、重复与权限检查的单条 SQL；整批成功或拒绝。兑换通过条件 UPDATE RETURNING 原子认领，同一码只能归属一个账户，同一账户同区重复提交返回原记录。核销和记录读取都重新检查当前分区发布、审核、店铺权限、封禁与 Adult 限制。私密响应禁止共享缓存；记录按领取地区和当前可见性过滤。商家导入与用户兑换均要求 Turnstile 和独立原子业务配额。详见 [卡密兑换](redemptions.md)。

## 商品评论

评论资格绑定同商品、同地区的成功兑换记录，在 SQL 条件写入中同时复核当前商品可见性与封禁状态。一账户每商品每地区一条评论，支持本人编辑及清空正文的软删除；管理员隐藏状态单独保存，不能通过删除重发绕过。公开评论仅包含昵称、正文、时间与已兑换标记，不包含认证或交付数据。

目录、兑换和评论共用发布可见性 SQL；公开读取和资格检查按用户操作触发，有界分页、配额和无共享缓存。评论举报独立建表，管理队列合并后最多 100 条，管理员按实际举报类型处理并记录审计。详见 [商品评论](comments.md)。

## 两套定义，仅测试开通

| 项目 | 生产定义 | 测试部署 |
| --- | --- | --- |
| 分支 | `main` | `test` |
| 状态 | 禁用、未开通 | 唯一允许发布的环境 |
| 主 Worker | `vrclearn-store` | `test-vrclearn-store` |
| 辅助 Worker | `vrclearn-store-support` | `test-vrclearn-store-support` |
| 站点 | `store.vrclearn.com` | `test-store.vrclearn.com` |
| 媒体 | `store-media.vrclearn.com` | `test-store-media.vrclearn.com` |

环境清单保留两套名称和代码结构。生产不持有云资源 ID、不接入发布触发器；请求发布生产时，在任何 Cloudflare 请求之前失败。测试新建 D1、R2、KV、DO、限流、认证 Secret、Turnstile、Access 和发布控制 D1，不能引用退役资源或复制旧数据。

`test` 验证后直接 PR 合入 `main`，不在合并时修改环境配置或复制数据。将来开通生产属于独立操作，不能由一次合并隐式完成。隔离针对可信开发中的缺陷、误操作和误配置；构建预检不是抵御恶意代码的权限边界。

## 发布与运行边界

Workers Builds 在固定分支的不可变 checkout 上运行：身份/资源校验 → 持锁 → 测试与一次构建 → 安全迁移 → 辅助 Worker → 主 Worker 与资产 → 两版本和绑定读回 → Access 与业务冒烟。

发布控制数据库只供构建期访问，保存本环境租约、SHA、阶段、两个 Worker 版本和迁移校验和；不绑定业务运行时。旧 SHA、并发发布、迁移失败、版本不一致或未知写入均阻止成功；写入结果不明时保留锁，人工读回后恢复，不自动抢锁或重放上传。

全新空库仅允许执行固定摘要的 `0001_initial.sql`；已有未知表而无迁移账本时拒绝初始化。后续自动迁移只允许新表、索引和安全新增列，拒绝数据改写、删除、未知结构及历史迁移修改，不自动回滚数据库。

业务运行时不持有部署、账单或 WAF 控制令牌。项目没有账单监控或预算状态分发，也没有美元阈值停机；业务配额、参数校验、限流、CPU 限制及有界清理继续独立工作。

## 内部访问与公开上线

测试站点与媒体共用本测试环境的 Access 应用，仅允许 `@vrclearn.com` 用户；专属 Service Auth 身份仅用于发布冒烟。Access 准入不授予商店账号或管理员角色。主/辅助 Worker 的默认域、版本 URL、R2 默认公开入口均关闭，不能绕过 Access。

正式公开或移除 Access 前，必须先提醒清空内测数据库，并核对测试媒体和配额状态；实际删除另行明确授权。部署是否完成以真实云端读回和验收为准。
